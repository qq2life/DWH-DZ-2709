# Craft Market DWH Project

Учебный проект по обновлению DWH и созданию инкрементальной витрины по заказчикам.

## Состав проекта

- `project.sql` — итоговый SQL-скрипт.

## Что делает скрипт

1. Собирает данные из `source1`, `source2`, `source3` и `external_source`.
2. Обновляет `dwh.d_craftsman`, `dwh.d_product`, `dwh.d_customer`.
3. Обновляет `dwh.f_order`.
4. Создаёт `dwh.customer_report_datamart`.
5. Создаёт `dwh.load_dates_customer_report_datamart`.
6. Выполняет инкрементальное обновление витрины.

## Гранулярность витрины

Одна строка = один заказчик за один отчётный месяц.

## Показатели

- сумма покупок;
- доход платформы 10%;
- количество заказов;
- средняя стоимость заказа;
- медианное время выполнения заказа;
- самая популярная категория;
- самый популярный мастер;
- количество заказов по статусам;
- количество незавершённых заказов;
- отчётный период `YYYY-MM`.

## Запуск

При первичном развёртывании выполните `project.sql` целиком.

При регулярных обновлениях не нужно повторно выполнять DDL-блок с
`DROP TABLE / CREATE TABLE` для витрины. Достаточно выполнить загрузку данных
в DWH и блок инкрементального обновления витрины.
